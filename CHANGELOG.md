## [0.9.0] — 2026-10-23

- Умное предложение замены сотрудников в связи с отсутствием.
- Персональная готовность соисполнителей и миграция `0009`.
- Экспорт руководительских отчётов в `.xlsx`.

# Changelog

Все значимые изменения Task Tracker фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Проект использует Semantic Versioning в формате `MAJOR.MINOR.PATCH`.

## [0.8.3] — 2026-10-23

### Добавлено

- Дополнительные исполнители одной задачи (`Task.additional_assignees`); один основной сотрудник сохранён ради обратной совместимости.
- Передача основной роли по больничному/отпуску с обязательной причиной и отдельной историей `TaskHandover`.
- Выбор нескольких соисполнителей в форме создания и редактирования задачи.
- Права доступа, уведомления, комментарии, поиск, календарь, Kanban, «Сегодня», загрузка и аналитика учитывают всех текущих участников задачи.
- Уведомления о добавлении в команду и изменениях по задаче.
- Миграция `0008_team_assignments_handovers` и регрессионные тесты.

### Сохранено

- Визуальная таблица загрузки сотрудников; права ответственных руководителей; ранее созданные задачи; Windows/Linux backup; оформление версии 0.8.2.

## [0.8.2] — 2026-10-22

### Интерфейс

- Переключатель темы перенесён из фиксированного положения над контентом в навигационную панель: больше не перекрывает кнопки страниц.
- Вместо неподвижного шнура — компактная лампочка с кликом и перетягиванием шнура вниз. Короткая анимация, работа с клавиатурой и `prefers-reduced-motion`.
- На узком экране тема по-прежнему меняется из меню профиля; на экране входа компактная лампочка доступна справа.
- Кнопка выхода в меню профиля получила оригинальную анимацию по мотивам Uiverse: небольшое движение стрелки, мягкий красный hover без смещения самого меню.
- Сохранены POST + CSRF при выходе и ключ `task-tracker-theme` для уже выбранных тем.
- Выделен `static/css/microinteractions.css`; внешние GSAP/CDN-зависимости не добавлены.

## [0.8.1] — 2026-10-22

### Исправлено

- Убраны зависящие от шрифта символы `⌄` в выпадающих меню.

## [0.8.0] - 2026-10-22

### Интерфейс и UX

- Упрощена навигация: основные разделы, меню «Ещё», меню профиля, активный пункт.
- Поиск доступен по Ctrl+K и `/`, добавлены контекстные фрагменты совпадений.
- Панель задачи: скрываемые дополнительные фильтры, сохранённые личные представления,
  настройка колонок на пользователя и компактный вид.
- Массовые операции показываются после выбора задач; изолированы полномочия Managers.
- Кликабельные KPI Dashboard и пояснения к задачам, требующим внимания.
- На странице сотрудника «Сегодня» доступны прямые действия со статусом.
- Карточка задачи упрощена, главный CTA акцентирован; историю можно развернуть.
- Форма задачи адаптирована под две колонки; полная таблица загрузки отдела сохранена.
- Для мобильного календаря добавлен режим списка по дням.
- Для Kanban добавлены управление пустыми колонками и улучшение заголовков.
- Загрузка: масштабы месяц/2 недели/неделя и всплывающие данные задач.
- Уведомления: фильтр непрочитанных и группировка по датам.
- На мобильных устройствах шнур темы скрыт, тема доступна в меню профиля.
- Логин использует фирменную крыску вместо букв TT.
- Добавлены единый keyboard focus, touch targets и новая структура CSS:
  `tokens.css`, `components.css`, `pages.css`.

### Совместимость

- Политика доступа и существующие данные не меняются, новых миграций нет.
- Скрипты Windows/Raspberry Pi backup сохранены.

## [0.7.1] - 2026-10-21

### Добавлено

- Ежедневный portable backup для Windows + Docker Desktop.
- `scripts/backup_windows.ps1`: PostgreSQL + media → `.tar.gz` + `.sha256` на диске Windows вне Docker volumes.
- `scripts/install_backup_task_windows.ps1`: регистрация ежедневного backup в Планировщике заданий Windows.
- `scripts/uninstall_backup_task_windows.ps1`: удаление автоматической задачи.
- Ротация старых Windows backup и текстовый журнал `backup_windows.log`.

### Изменено

- Документация backup теперь описывает как Raspberry Pi/systemd, так и тестовый Windows/Docker Desktop сценарий.
- Windows backup использует тот же состав данных (`database.dump`, `media.tar.gz`, manifest), чтобы копию было проще перенести на Raspberry Pi.

## [0.7.0] - 2026-10-21

### Добавлено

- Отдельное поле `responsible_manager`: автор задачи и ответственный руководитель больше не смешиваются.
- Передача ответственности между Managers с фиксацией в истории и уведомлением нового руководителя.
- Массовые операции над задачами: исполнитель, ответственный руководитель, приоритет и срок.
- Глобальный поиск по `#ID`, названию, описанию, сотрудникам, ответственным руководителям и комментариям.
- Персональные сохранённые фильтры задач для каждого пользователя.
- Переносимый host-backup PostgreSQL + media в одном `.tar.gz` с SHA-256, сохраняемый вне Docker volumes.
- Systemd timer для ежедневного backup на Raspberry Pi.

### Изменено

- Права проверки/закрытия и уведомления теперь опираются на `Task.responsible_manager`, а `created_by` остаётся неизменяемым автором.
- Старые задачи автоматически получают `responsible_manager = created_by` при миграции.
- Pre-deploy backup GitHub Actions использует общий host-backup script.
- Таблица задач получила колонку ответственного руководителя и безопасные checkbox для массовых операций.

### Исправлено

- Удалена лишняя закрывающая скобка в `task_detail` view, попавшая в предыдущую рефакторенную сборку.

## [0.6.0] - 2026-10-21

### Добавлено

- Общая адаптивная ширина интерфейса почти на весь экран с небольшими боковыми отступами.
- Перенос названий задач в шкале загрузки до двух строк и автоматическое выравнивание длинных подписей влево.
- Явный режим read-only для задач, созданных другим руководителем.

### Изменено

- Manager управляет только задачами, которые создал сам; другие задачи доступны ему для просмотра.
- Очередь проверки и уведомления о результате привязаны к `Task.created_by`.
- Проверки прав Managers перенесены из промежуточного `manager_views.py` в основной `views.py`.
- Контекст страницы задачи централизован, чтобы права не расходились между GET и ошибочными POST.
- Широкие стили таблицы задач ограничены только таблицей задач и больше не влияют на остальные таблицы.

### Рефакторинг

- Удалены временные файлы старых patch-итераций.
- Удалены неиспользуемые стили старого кастомного login dropdown.
- Добавлен отдельный `static/css/layout.css` для общей геометрии страниц.

## [0.5.0] - 2026-10-20

### Добавлено

- Полный жизненный цикл задачи:
  - `Новая`;
  - `В работе`;
  - `На проверке`;
  - `На доработке`;
  - `Выполнена`;
  - `Отменена`.
- Проверка результата руководителем с принятием или возвратом на доработку.
- Обязательная причина возврата на доработку.
- Уведомления исполнителя о принятии или возврате задачи.
- Уведомления группы `Managers` о задачах, отправленных на проверку.
- История изменений задачи.
- Фактические даты:
  - начала работы;
  - отправки на проверку;
  - окончательного завершения.
- Отдельная очередь задач, ожидающих проверки.
- Комментарии внутри задачи.
- Быстрые действия изменения статуса.
- Kanban-представление.
- Цветные статусы и приоритеты.
- Быстрые фильтры/chips и фильтрация без кнопки «Применить».
- План загрузки сотрудников с режимами «Текущие» / «Все задачи».
- Фото и скриншоты в задачах.
- Учёт отсутствий сотрудников.
- Аналитика руководителя.
- Activity feed.
- Номера задач вида `#123`.
- UI-улучшения: breadcrumbs, копирование ссылки, compact table mode, sticky headers.
- Backup PostgreSQL и пользовательских изображений перед production deploy.
- CI/CD через GitHub Actions и self-hosted runner на Raspberry Pi.

### Изменено

- Финальный статус `Выполнена` подтверждается руководителем.
- Задачи `На проверке` отображаются как текущие, но не увеличивают рабочую нагрузку исполнителя.
- Расчёт загрузки учитывает только фактическую текущую работу сотрудника.
- Интерфейс задачи переработан под ежедневную работу сотрудника и руководителя.

### Инфраструктура

- Python 3.13.
- Django 5.2 LTS.
- PostgreSQL 17.
- Gunicorn.
- Nginx.
- Docker Compose.
- Raspberry Pi 5 как production host.
