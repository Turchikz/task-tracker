# RaTracker v0.19.9 — проектные метки и новые открытия мышки

## Задачи и проекты

- Руководитель может добавлять к задаче метки, включая название проекта,
  например `1202.55 ООО Ачимгаз`.
- Новое название создаётся при сохранении задачи и затем предлагается через
  список автодополнения. Можно задать до восьми меток, разделяя их запятой
  или точкой с запятой.
- Список задач можно фильтровать по проекту/метке и по срокам в ближайшие
  семь дней. Фильтр метки сохраняется в персональном представлении.
- Метки показываются в списке и карточке задачи. Сотрудник видит метки только
  у доступных ему задач и не управляет общим списком.

## Мышка

- За поимки открываются окрасы на 5, 15 и 30 поимках и аксессуары на 10,
  25 и 50 поимках. Прогресс синхронизируется вместе со счётчиком поимок.
- Иногда мышка выглядывает, оставляет сырные крошки или быстро ускользает.
- В меню «Звуки и пасхалки» отдельно настраиваются показ мышки, следы лапок,
  визуальные реакции и звуки.
- Все игровые открытия зависят только от поимок мышки и не связаны с задачами.

## Обновление

Примените миграцию `0018_tasktag_task_tags` вместе с обычным обновлением:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
