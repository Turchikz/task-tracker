# RaTracker / Task Tracker v0.8.0 — UI/UX

Обновление поверх **v0.7.1**. Полный архив с исходным кодом, шаблонами,
миграциями, Docker Compose и backup-скриптами. **Новых миграций нет.**

## Что обновилось

1. **Компактная навигация:** главные разделы, меню «Ещё», профиль, кнопка новой задачи,
   сокращённая кнопка уведомлений и выделение открытого раздела.
2. **Навигация по клавиатуре:** `Ctrl+K` / `⌘K` или `/` — поиск, `Esc` — закрыть меню;
   единая заметная рамка фокуса.
3. **Ширина страниц:** таблицы/канбан/календарь используют всё окно, формы и текстовые
   разделы ограничены по удобочитаемой ширине.
4. **Задачи:** быстрое переключение статусов, скрытая до вызова панель подробных фильтров,
   персональные сохранённые представления, настройка дополнительных колонок,
   компактный вид. Последние две настройки сохраняются в текущем браузере
   с ключом пользователя. Сохранённые фильтры по-прежнему находятся в БД.
5. **Массовые операции:** панель появляется только после выделения задач;
   авторизация на сервере по ответственному Manager сохранена.
6. **Дашборд:** кликабельные KPI и пояснения причин привлечения внимания.
7. **«Сегодня»:** прямые кнопки «Начать работу» / «На проверку».
8. **Карточка задачи:** более чёткое основное действие, меньше повторяющихся сведений,
   история свёрнута после пяти событий и раскрывается одной кнопкой.
9. **Форма задачи:** адаптивная сетка полей из двух колонок на широких экранах;
   **наглядная таблица загрузки сотрудников сохранена без изменения состава колонок**.
10. **Календарь:** месяц / повестка по дням. На узком экране список выбирается
    автоматически (кнопки доступны для ручного переключения).
11. **Канбан:** возможность скрыть пустые колонки и более удобные заголовки.
12. **Загрузка:** масштабы «месяц», «2 недели», «неделя» и подсказки при наведении.
    Перенос/обрезка длинных подписей из предыдущей версии сохранены.
13. **Уведомления:** все / непрочитанные, группировка «Сегодня» / «Вчера» / «Ранее».
14. **Поиск:** пояснение, в комментарии или описании найдено совпадение; поиск
    по-прежнему соблюдает права пользователей.
15. **Тема и брендинг:** декоративный шнур темы оставлен на desktop; на мобильном
    переключатель находится в меню профиля. На входе вместо «TT» — фирменная крыска.
16. **CSS:** добавлены `tokens.css`, `components.css`, `pages.css`;
    прежние стили сохранены для совместимости. Следующий этап — поэтапно переносить
    оставшиеся legacy-правила в новые слои без изменений отображения.

## Установка на локальной Windows + Docker Desktop

1. **Сделайте резервную копию данных ДО обновления**:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\scripts\backup_windows.ps1
   ```

2. Сохраните свой `.env` и существующие Docker volumes. **Не выполняйте**
   `docker compose down -v` — эта команда удаляет volumes с данными.
3. Замените файлы проекта содержимым архива, не заменяя свой `.env`.
4. В корне проекта выполните:

   ```powershell
   docker compose up -d --build
   docker compose exec web python manage.py check
   docker compose ps
   ```

5. Откройте сайт и выполните `Ctrl + F5`, чтобы сбросить старые стили.
6. Чтобы выполнить тесты, в отдельном окружении с установленными
   `requirements-dev.txt` используйте `pytest`. В CI это выполняется автоматически.

## Перенос на Raspberry Pi

Структура Docker Compose и система резервных копий не изменены. Если репозиторий
подключён к CI/CD, сначала пройдут тесты на GitHub Actions; затем будет вызван
преддеплойный backup и обновление на сервере.

- JavaScript-синтаксис: `node --check`.

которые необходимо запустить в проектном окружении до выкладки на рабочий сервер.
