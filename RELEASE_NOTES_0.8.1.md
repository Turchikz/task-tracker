# Task Tracker v0.8.1 — исправление стрелок меню

Точечное визуальное исправление по скриншотам v0.8.0.

- Убраны текстовые символы `⌄`, которые в некоторых шрифтах выглядят как неаккуратные галочки.
- Добавлены аккуратные CSS-стрелки с одинаковым размером, отступами и вращением при открытии меню.
- Исключено появление дополнительных системных маркеров у элемента `summary`.
- Изменены только `templates/base.html`, `templates/tasks/task_list.html`, `static/css/components.css`, версия и документация.

## Установка

Для полного архива — скопируйте содержимое `task-tracker/` поверх вашего каталога проекта, сохранив `.env`.
Для мини-архива — распакуйте файлы прямо в корень проекта с заменой.

После обновления:

```powershell
docker compose up -d --build
```

Откройте страницу с Ctrl+F5. Миграций не требуется.
