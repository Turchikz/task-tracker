# RaTracker v0.8.2 — лампочка и выход

## Что изменилось

- Компактный анимированный выключатель-лампочка в верхней панели (по мотивам [Jh3y](https://codepen.io/jh3y/pen/VwjgdLj)).
- Переключение по нажатию, Enter/Space или вытягиванию шнура мышкой/пальцем. Нет внешних JS-библиотек.
- Лампочка светится в светлой теме и гаснет в тёмной.
- В профиле адаптирована кнопка выхода по мотивам [Uiverse](https://uiverse.io/vinodjangid07/thin-duck-22): сдержанный hover, плавное движение стрелки, без прыжков компоновки.
- На мобильном экране переключение темы остаётся в меню профиля, поскольку дополнительная лампочка заняла бы место в шапке. На экране входа лампочка остаётся доступна.
- Закрытие сессии работает через прежнюю Django форму POST + CSRF.
- Сохранён существующий ключ localStorage `task-tracker-theme`, настройки пользователя не сбрасываются.

## Установка

Для полного архива: распакуйте содержимое папки `task-tracker/` в корень своего проекта, предварительно сохранив `.env` и локальные изменения.

Для мини-архива: распакуйте только изменённые файлы прямо в корень проекта с заменой. Удаление старого кода не требуется: старые стили лампочки удалены из `theme.css`.

```powershell
docker compose up -d --build
docker compose exec web python manage.py check
```

После обновления сделайте `Ctrl+F5`. Миграций не требуется. Тесты Django и интерактивный браузер здесь не запускались; JS проверен через `node --check`, Python — через `compileall`.
