# RaTracker v0.8.3 — передача и совместная работа

Два изменения:

1. **Передать задачу**: выбрать нового основного исполнителя, указать причину (больничный, отпуск), при желании оставить прежнего соисполнителем. Сроки, статус, дата фактического начала, вложения и комментарии сохраняются. Передача попадает в историю и отдельную таблицу `TaskHandover`.
2. **Несколько исполнителей**: отметить дополнительных сотрудников в форме задачи. У задачи один общий статус; каждый участник видит задачу и учитывается в своей загрузке.

Исправлены проверки доступа, уведомления, список задач, фильтры сотрудников, «Сегодня», Kanban, календарь, отчёт и поиск.

## Обновление с v0.8.2

Сначала сделайте резервную копию PostgreSQL и media. Распакуйте полный архив поверх проекта, не заменяя `.env`.

```powershell
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py check
docker compose exec web pytest tests/test_v083_collaboration.py
docker compose exec web pytest
```

Миграция: `tasks/migrations/0008_team_assignments_handovers.py`. Она сохраняет данные существующих задач. Если стандартный `entrypoint.sh` уже выполняет `migrate`, повторная команда безопасна.

## Правила совместной задачи

- Основной исполнитель один; дополнительных может быть несколько.
- Любой назначенный сотрудник может начать работу или отправить общий результат на проверку.
- Принимает/отклоняет результат ответственный руководитель.
- При передаче старая запись задания не удаляется, прогресс не обнуляется.
- Наглядная таблица загрузки сотрудников в форме сохранена.

Детали и ограничения: `docs/collaboration_and_handover.md`.
