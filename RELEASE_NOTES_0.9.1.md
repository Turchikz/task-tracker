# RaTracker v0.9.1 — звуки и мышка

- Локальные синтезированные звуки Web Audio без CDN и дополнительных зависимостей.
- Сигналы уведомлений, назначений, сроков, доработки, принятия и выполнения.
- Щелчок переключателя темы; звуковые API для сохранения/ошибки/выполнения дня.
- Мышка пробегает примерно каждые 10–20 минут на desktop, четыре варианта поимки, редкая золотая мышка и серия поимок.
- Персональные настройки в меню профиля: уведомления, эффекты, шаги мышки, громкость. По умолчанию выключены.
- Новые уведомления опрашиваются раз в 30 секунд, старые не воспроизводятся при открытии.
- Учитывается prefers-reduced-motion; звук запускается только после взаимодействия пользователя.
- Настройки локальны для пользователя и браузера, без синхронизации между устройствами.
- Новых миграций нет.

**Важно:** функции `RaTrackerSound.play("save")`, `play("error")`, `play("all-done")` доступны для будущей привязки к конкретным событиям приложения, но пока не подключены к этим событиям.

Обновление: `docker compose up -d --build`; `docker compose exec web python manage.py check`.
