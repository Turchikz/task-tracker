# RaTracker v0.9.10 — уведомления чата

- Индивидуальные настройки в PostgreSQL: всплывающие уведомления внутри сайта, системные уведомления Windows, звуковой сигнал, приоритет упоминаний и громкость.
- Настройки доступны на странице /chat/ по кнопке «Настройки уведомлений».
- События чата проверяются каждые 3 секунды на всех открытых страницах RaTracker.
- На свои сообщения уведомления не отправляются. Несколько сообщений в одном цикле дают одно уведомление; попытка подавить дубликаты между вкладками реализована через localStorage.
- В открытом активном чате оповещения не мешают чтению; счётчик непрочитанных работает независимо.
- Для системных уведомлений браузер должен разрешить уведомления, а сайт должен открываться через HTTPS либо localhost. По HTTP с адреса локальной сети браузеры обычно запрещают Notification API.
- При полностью закрытом браузере уведомления не доставляются. Web Push не включён в эту версию.
- Запустить: docker compose up -d --build; docker compose exec web python manage.py migrate; docker compose exec web python manage.py collectstatic --noinput.
- Не удалять Docker volumes с PostgreSQL. Не заменять рабочий .env.
