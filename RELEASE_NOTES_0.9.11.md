# RaTracker v0.9.11 — XLSX-отчёт о работе отдела

На странице «Загрузка сотрудников» добавлены две даты и кнопка «Скачать XLSX».
Экспорт доступен руководителям и администраторам и всегда включает все статусы,
независимо от выбранного на странице фильтра задач.

## Содержание

- «Итоги отдела»: создано и выполнено за период, выполнено в срок, с опозданием
  и без срока, доля в срок среди выполненных со сроком; результаты сотрудников.
  Завершение определяется по completed_at и текущему статусу «Выполнена»,
  создание — по created_at. Обе границы периода включены.
- «План ГГГГ-ММ»: отдельный календарь каждого месяца, цвета приоритетов,
  завершённые серые полосы, отсутствия, выходные и праздники производственного
  календаря. Закреплены шапка и столбцы сотрудников. Балл нагрузки — текущий.
- «Все задачи»: по одной строке на задачу, полные названия, исполнители,
  статус, приоритет, трудоёмкость, руководитель, плановые и фактические даты.
  Доступны фильтры, перенос текста и ссылки на задачи.

В реестр входят задачи, чей план пересекает период, а также созданные или
выполненные в периоде. Задачи без срока включаются с отдельной пометкой
независимо от периода, поскольку их нельзя однозначно отнести к плану.
Задачи без планового начала показываются в день срока, как на сайте.
Если выполнение попало в месяц, а план не пересекает этот месяц,
задача показывается отметкой в день завершения. Короткая полоса содержит ID;
полное название доступно в реестре. Длинный период разбивается по месяцам,
без обрезания дат (годы 2000–2100).

Совместная задача считается один раз в итоге отдела и у каждого исполнителя
в персональной статистике. Включены и неактивные исполнители выбранных задач.
Статусы, состав команды, балл и счётчики нагрузки — на момент выгрузки;
исторический состав команды и балл на прошедшую дату не восстанавливаются.
Это отмечено непосредственно в файле.

## Обновление

Сделайте резервную копию БД и media. Распакуйте проект поверх текущего,
сохраните рабочий .env и Docker volumes. Выполните:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```

Новых зависимостей и миграций в 0.9.11 нет. Сохраняются функции 0.9.10.

## Проверка

Тесты экспорта покрывают права доступа, неверные даты, один день, переход
месяца, совместные задачи, неактивного сотрудника, выполнение вне плановых
дат, отсутствие, задачи без срока и защиту от формул в пользовательском тексте.
Проверены структура XLSX и оформление трёх типов листов на демоданных.

Полный набор: 138 тестов пройдено; 7 прежних падений воспроизведены также
на исходной 0.9.10 (136 пройдено, те же 7 падений). Они относятся к старым
ожиданиям тестов уведомлений, проверки задач, фильтров и подписи праздника,
а не к экспорту. Django system check пройден.
