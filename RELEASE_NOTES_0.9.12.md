# RaTracker v0.9.12 — идеи, лампа, чат и календарь

- На странице идей полоса показывает соотношение поданных голосов: зелёная
  часть «За», красная «Против». При равенстве 2:2 — две равные половины.
  При отсутствии голосов полоса нейтральная. Отдельно показаны поддержка от
  всех активных сотрудников и прежний порог 80% для рассмотрения.
- Переключение темы кликом, клавиатурой или потягиванием шнура лампы
  сопровождается разными короткими звуками включения и выключения.
  Звук подчиняется уже существующим персональным настройкам «Звуковые эффекты»
  и «Громкость» в меню «Звуки и пасхалки», поэтому его можно выключить.
  Браузер воспроизводит звук после первого действия пользователя.
- В чате более 100 эмодзи, сгруппированных по лицам, жестам, символам,
  работе и веселью. Эмодзи вставляется на месте курсора; Esc закрывает панель.
- В месячном календаре и представлении «Список» сотрудник видит имена всех
  отсутствующих коллег в соответствующие даты, без необходимости доступа
  к странице управления отсутствиями. Даты периода доступны в подсказке;
  причина отсутствия не выводится. Календарная ячейка растёт по содержимому.

Сохранены все функции 0.9.11, включая XLSX-отчёт по загрузке отдела и
персональные уведомления чата. Миграций и новых зависимостей нет.

Для обновления сохраните рабочий `.env` и Docker volumes, создайте резервную
копию БД и media, затем выполните:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```

Проверка: 140 тестов пройдено; 7 прежних падений воспроизведены на исходной
0.9.10 и 0.9.11. Новые тесты проверяют 2:2 среди пяти сотрудников (50% полоса,
40% поддержка отдела), отсутствие голосов, имена всех отсутствующих в
календаре сотрудника и режим списка. JavaScript проверен на синтаксис;
`manage.py check` пройден.
