# RaTracker v0.9.13 — следы мышки и сырная копилка

Во время пробежки мышка оставляет маленькие следы лапок, которые быстро
исчезают и не мешают нажимать кнопки. При поимке появляются кусочки сыра,
одна из трёх реплик и пополнение «Сырной копилки» на 1. Редкая золотая
мышка даёт 5. Счётчик показан в меню «Звуки и пасхалки», хранится отдельно
для каждой учётной записи в этом браузере и не влияет на задачи или
статистику отдела. При очистке данных браузера или на другом устройстве
он не переносится.
При 10 и 50 кусочках пользователь получает шуточное звание, которое тоже
видно в этом меню.

Существующие звуковые переключатели по-прежнему управляют эффектами и
шагами мышки. Следы и сырный эффект отсутствуют при включённой настройке
системы «Уменьшить движение», как и сама анимированная мышка. При скрытой
вкладке таймер пробежки не ускоряется; текущая пробежка прекращается.

Для быстрой ручной проверки на компьютере откройте консоль браузера и
выполните `RaTrackerMouse.spawn()` или
`RaTrackerMouse.spawn({legendary:true})`. Статус и число сыров:
`RaTrackerMouse.status()`.

Сохранены все функции v0.9.12. Новых миграций и зависимостей нет.
Обновление: резервная копия БД и media, сохранить `.env` и Docker volumes,
распаковать проект, затем:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
