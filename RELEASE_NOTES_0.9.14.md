# RaTracker v0.9.14 — быстрая мышка и сырная лавка

После каждой поимки мышка ускоряется на 3,5% относительно прежней скорости.
Рост ограничен 30 поимками (+105%), длительность пробежки — не менее двух
секунд. Золотая мышка считается одной поимкой, хотя приносит пять сыров.
Промахи не меняют скорость. Текущее число поимок и прибавка отображаются
в меню «Звуки и пасхалки».

Сыр из копилки можно обменять на шапку (5) и шарфик (8) в «Сырной лавке»
этого меню. Каждую вещь покупают один раз; после покупки она появляется
на следующих мышках. Цвета меняются случайно при каждом появлении,
а у шапки и шарфика на одной мышке они не совпадают. Покупки уменьшают
остаток сыра, но не отменяют уже полученные шуточные звания.

Остаток сыра из v0.9.13 сохраняется. Ранее число поимок не записывалось,
поэтому отдельный счётчик стартует с нуля при обновлении. Копилка, покупки
и счётчик сохраняются для конкретной учётной записи в данном браузере:
на другом устройстве или после очистки данных браузера они не появятся.
Эта игра не влияет на задачи и статистику отдела. При включённой системной
настройке «Уменьшить движение» анимация мышки остаётся выключенной.

Для ручной проверки в консоли браузера: `RaTrackerMouse.spawn()`,
`RaTrackerMouse.spawn({legendary:true})` и `RaTrackerMouse.status()`.

Сохранены все функции v0.9.13. Новых миграций и зависимостей нет.
Перед обновлением сделайте резервную копию БД и media, сохраните `.env`
и Docker volumes. После распаковки проекта:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
