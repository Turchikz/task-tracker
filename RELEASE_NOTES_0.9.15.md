# RaTracker v0.9.15 — синхронизация сырной копилки

Сыр, суммарный заработок, число поимок и купленные шапка с шарфиком
сохраняются в базе данных на учётную запись. После входа с другого
устройства копилка показывает те же значения. Настройки звука остаются
локальными для браузера, а игровые данные не влияют на рабочие показатели.

При первом открытии версии прежний прогресс из браузера отправляется на
сервер. Импорт выполняется только один раз на пользователя: если старый
прогресс был на нескольких устройствах, суммировать его автоматически
нельзя — это могло бы удвоить сыр. Если связи нет, поимки остаются в
локальной очереди и отправляются после восстановления соединения или
перезагрузки страницы. Каждое действие имеет идентификатор, поэтому
повторная отправка не начисляет награду дважды. Покупки сверяются с
серверным остатком; при одновременной покупке на двух устройствах
вторая может быть отклонена и интерфейс обновится.

Сохранены все функции v0.9.14. Нужна новая миграция `0013_mouse_wallet`.
Проверка: 10 адресных тестов и 3 браузерно-логических теста прошли,
`manage.py check` без замечаний. Полный набор: 144 прошли, 7 падений
в прежних тестах уведомлений, фильтров, задач и календаря остались
без изменений относительно v0.9.14.
Перед обновлением сделайте резервную копию БД и media, сохраните `.env`
и Docker volumes. После распаковки проекта:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
