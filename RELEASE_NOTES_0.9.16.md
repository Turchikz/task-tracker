# RaTracker v0.9.16 — рулетка по темам

В меню «Ещё» всем вошедшим пользователям доступна «Рулетка».
Руководитель создаёт отдельную тему, например «Командировка», и задаёт
число выбираемых сотрудников (по умолчанию три, от одного до двадцати).
Перед каждым розыгрышем можно вручную исключить людей. Участвуют только
активные учётные записи группы Employees. Победители выбираются на
сервере случайно и без повторений внутри одного розыгрыша.

Результат видят все сотрудники. Открытая страница темы проверяет новые
итоги и обновляется; каждый розыгрыш сохраняет участников, исключённых,
победителей, дату и запустившего руководителя. История каждой темы
отдельная и доступна постранично. Повторная отправка той же формы не
создаёт второго результата. На устройствах с настройкой «Уменьшить
движение» анимация колеса сокращается.

Ссылка «Как считается нагрузка» удалена из меню сотрудников; прямой
адрес этой страницы возвращает 403 для сотрудника. Руководителям
страница по-прежнему доступна.

Нужна новая миграция `0014_roulette`. Проверки: 11 адресных тестов,
проверка Django и миграций прошли. Полный набор: 147 прошли, прежние
7 падений в тестах других разделов остаются без изменений.

Перед обновлением сделайте резервную копию БД и media, сохраните `.env`
и Docker volumes. После распаковки проекта:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
