# RaTracker v0.9.17 — версия в меню и управление результатами

Номер версии показывается в меню профиля непосредственно после раздела
«Звуки и пасхалки». Значение берётся из основного файла `VERSION`,
поэтому оно соответствует установленной сборке.

Администратор с правами superuser может удалить отдельный результат
рулетки. Он исчезает из публичной истории и перестаёт считаться
последним результатом; открытые страницы обновляются автоматически.
Удаление обратимо: запись и состав участников сохраняются в разделе
«Удалённые результаты» этой темы, откуда администратор может её
восстановить. Руководители без прав superuser и сотрудники не видят
кнопки и не могут вызвать действие напрямую. Повтор старой отправки
удалённого розыгрыша не создаст результат заново.

Нужна миграция `0015_roulette_draw_soft_delete`. Проверка: 10 адресных
тестов прошли, `manage.py check` без замечаний; в полном наборе 150
тестов прошли и 7 прежних падений остались в других разделах.
Перед обновлением
сделайте резервную копию БД и media, сохраните `.env` и Docker volumes.
После распаковки проекта:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
