# RaTracker v0.9.18 — важные файлы и управление темами рулетки

В меню «Ещё» появился раздел «Важные файлы». Руководитель загружает
документ с названием, категорией и описанием. На карточке видны дата
последнего обновления и имя актуального файла. При замене сохраняются
прежние версии с датой загрузки и автором; скачать их может любой
вошедший пользователь. Поиск работает по названию и описанию,
доступна фильтрация по категориям.

Файлы сохраняются в существующем Docker volume `media_data` и выдаются
только через авторизованный маршрут как вложения. Разрешены PDF,
Word, Excel, ODT/ODS, TXT/CSV, JPG/PNG размером до 20 МБ.
Сохраняйте резервную копию БД и media вместе: они содержат записи и сами
файлы соответственно.

В Django Admin зарегистрированы темы рулетки. Администратор с правами
superuser может удалить целую тему. Перед подтверждением показывается
количество связанных розыгрышей; удаляются и активные, и скрытые
результаты этой темы. Это необратимая операция, восстановление возможно
из резервной копии. Для аккуратного удаления доступна только отдельная
страница темы, массовое действие отключено. Удаление одного результата
на странице рулетки остаётся обратимым.

Нужны миграции `0016_important_files` и `0017_roulette_topic_cascade`.
Адресные проверки прошли; `manage.py check` и проверка миграций — без
замечаний. В полном наборе 153 теста прошли, 7 прежних падений
в других разделах остались без изменений.
Перед обновлением сделайте резервную копию БД и media, сохраните `.env`
и Docker volumes. После распаковки проекта:

```bash
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check
```
