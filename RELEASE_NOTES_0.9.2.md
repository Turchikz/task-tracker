# RaTracker v0.9.2 — фоновый звук и таймер мышки

- Проверка новых уведомлений продолжается при переключении на другую вкладку браузера. Звуки возможны после взаимодействия пользователя с RaTracker и при разрешённом браузером воспроизведении аудио.
- Старые уведомления при первом опросе не озвучиваются.
- Мышка появляется только после 10–20 минут **активного времени на странице**, а не сразу после возвращения из фоновой вкладки.
- При уходе со страницы мышка удаляется, её таймер ставится на паузу.
- После пробуждения компьютера и задержек фоновых таймеров появление мышки не форсируется.
- Миграции не требуются.

Обновление: `docker compose up -d --build`, затем `Ctrl+F5`.
