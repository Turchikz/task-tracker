# RaTracker 0.9.5 — тестовый запуск мышки

В консоли браузера (`F12` → Console):

```javascript
RaTrackerMouse.spawn()
RaTrackerMouse.spawn({legendary: true})
RaTrackerMouse.remove()
RaTrackerMouse.status()
```

`spawn()` запускает существующую игровую мышку сразу, не меняя таймер естественного появления. Возвращает `true`, если запуск выполнен. Поддерживается в десктопном режиме при ширине экрана от 800 px, когда отключён системный режим уменьшения движения. Звук поимки зависит от настроек пользователя.

Старые данные и база не меняются, миграции не требуются.
