# RaTracker v0.9.6 — стабилизация интерфейса и статики

## Исправлено
- Обновлён и диагностируемый консольный API мышки: `window.RaTrackerMouse.spawn()`, `spawn({legendary:true})`, `status()` и `remove()`; `status()` сообщает версию и доступность.
- Громкость звуков: коэффициент 0.99, как выбран пользователем, с компрессором на выходе.
- Переработана палитра панели звуков и всплывающего сообщения о мышке: используются общие семантические токены для светлой и тёмной тем.
- Улучшен контраст placeholder, disabled-полей и focus-visible в тёмной теме.
- Исправлено горизонтальное смещение шнурка лампочки.
- Сброс кэша ассетов версии 096; Nginx перепроверяет JS и CSS вместо недельного кэширования.

## Проверка после обновления
1. `docker compose up -d --build` — контейнер web автоматически выполняет `collectstatic` через entrypoint.
2. В DevTools: `document.querySelector('script[src*="soundscape.js"]')?.src` → `?v=096`.
3. `fetch('/static/js/soundscape.js?v=096').then(r=>r.text()).then(s=>console.log(s.includes('window.RaTrackerMouse')))` → `true`.
4. `window.RaTrackerMouse.status()` → `{version:'0.9.6', ...}`; `window.RaTrackerMouse.spawn()`.
5. Переключить светлую/тёмную темы и проверить профиль → «Звуки и пасхалки», уведомления, формы и таблицы.

## Ограничения проверки
Проверены синтаксис JS, наличие файлов и целостность ZIP. В этой среде не запущены Docker Desktop, PostgreSQL и реальный браузер: визуальное соответствие оценено по CSS, а не по скриншотам работающего приложения. Перед установкой в отделе сделать резервную копию БД и медиа.
