# RaTracker v0.9.7

- Исправлена ошибка HTTP 500 на `/tasks/` у пользователей с сохранёнными фильтрами: сравнение `SavedTaskFilter.parameters` вместо несуществующего `query_string`.
- В фильтр «Исполнитель» для руководителей добавлено «Мои задачи (исполнитель или соисполнитель)». Значение `assigned=me` определяется динамически по текущему пользователю.
- Существующий механизм сохранения фильтров поддерживает комбинации статуса, приоритета, исполнителя, руководителя, просрочки и сортировки. JSONField и миграции не менялись.
- Мышка использует отдельный восьмикадровый PNG-спрайт `static/img/rat-run-sprite.png`, а не изображение логотипа в HTML. Анимация кадров — CSS `steps(8)`.
- Сохранены команды `RaTrackerMouse.spawn()`, `spawn({legendary:true})`, `status()` и `remove()`.
- Обновлены версии статических ресурсов для обхода браузерного кэша.

## Развёртывание

Сделать бэкап. Сохранить рабочий `.env` и Docker volumes. `docker compose up -d --build`, затем убедиться, что `collectstatic` отработал, и обновить страницу без кэша. Не использовать `docker compose down -v`.

## Ограничения проверки

Выполнены статические проверки кода и ZIP; реальное тестирование в Docker Desktop и браузере с рабочей БД не проводилось.
