# RaTracker v0.9.9

- Общий чат для всех авторизованных пользователей.
- HTTP polling каждые 3 секунды, история постранично по 50 сообщений.
- Эмодзи, @упоминания с выбором сотрудника, ответы на сообщения.
- Счётчики непрочитанных и персональных упоминаний в меню (обновление раз в 15 секунд).
- Ограничение 2000 символов и базовое ограничение частоты отправки (2 секунды).
- Автоматическая очистка сообщений старше шести календарных месяцев через сервис chat-cleanup.
- Миграция 0011_department_chat.

## Обновление
Сохраните `.env` и резервную копию PostgreSQL. `docker compose up -d --build` запускает миграции через штатный entrypoint. Затем `docker compose exec web python manage.py showmigrations tasks`.

Вложения, личные переписки и WebSocket не входят в релиз. Сообщения в резервных копиях могут храниться дольше шести месяцев.
