RaTracker 0.9.18 — полная версия проекта

Новое: раздел «Важные файлы» с датой последнего обновления,
поиском и категориями. Руководители загружают и обновляют документы,
все сотрудники скачивают актуальные и предыдущие версии.
Администратор может удалить всю тему рулетки вместе с историей
через Django Admin после отдельного подтверждения.
Сохранено: в меню профиля после «Звуки и пасхалки» показана версия из
файла VERSION. Администратор (superuser) может убрать отдельный
результат рулетки из общей истории и восстановить его при ошибке.
Сохранено: рулетка по отдельным темам. Руководитель создаёт тему,
задаёт количество победителей (по умолчанию 3), исключает сотрудников
перед запуском и проводит розыгрыш. Все вошедшие пользователи видят
результаты и историю темы. У сотрудников убрана ссылка на описание
расчёта нагрузки; прямой доступ к странице также закрыт.
Сохранено: сырная копилка, счётчик поимок и покупки хранятся
на сервере для учётной записи и синхронизируются между устройствами.
При первом запуске прежний прогресс браузера переносится один раз.
При потере связи поимки ждут отправки и не начисляются дважды.
Сохраняется: мышка ускоряется после каждой поимки (до +105% к скорости),
а в «Сырной лавке» можно навсегда купить ей шапку за 5 сыров и
шарфик за 8. При каждом появлении цвета аксессуаров случайны и разные.
Настройки звука остаются локальными для браузера. Счётчик поимок
начал записываться в версии 0.9.14.
Сохранены: исчезающие следы лапок и сыр за поимку (золотая — 5),
титулы, настройки звуков и все функции предыдущих версий.
Сохранены: зелёная/красная полоса голосов идей, звук лампочки,
расширенный набор эмодзи в чате и все отсутствующие коллеги в календаре.
Сохраняется XLSX-отчёт по загрузке и работе отдела.

Перед обновлением сделайте резервную копию БД и media.
Сохраните существующий .env. Не удаляйте Docker volumes.

docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py collectstatic --noinput
docker compose exec web python manage.py check

Экспорт: Загрузка → даты «с» и «по» → Скачать XLSX.
Подробности и результаты проверок: RELEASE_NOTES_0.9.18.md.
