# Исторический аудит проекта — 2026-10-21

Этот документ фиксирует состояние и рефакторинг на 21 октября 2026 года. Часть рекомендаций аудита с тех пор реализована, поэтому список не следует использовать как текущий план работ.

В частности, к версии 0.9.18 уже добавлены ответственный руководитель и передача задач, массовые операции, сохранённые фильтры, поиск, XLSX-отчёты и operational monitoring. Текущая оценка проекта и актуальные предложения находятся в [обзоре проекта](project_review_2026-10.md).

Сохраняемая историческая архитектурная оценка: Django-монолит с PostgreSQL, Gunicorn/Nginx и Docker Compose подходит внутренней команде примерно из 15 человек; микросервисы для этого масштаба не нужны.
