# Рефакторинг интерфейса и прав доступа — 2026-10

## Что изменено

- Удалён промежуточный `manager_views.py`: проверки владельца задачи перенесены в основной `views.py`.
- Контекст страницы задачи собирается через единый `_task_detail_context`, чтобы права и формы не расходились между GET и ошибочными POST.
- Очередь проверки и manager-dashboard используют единый `_manager_owned_queryset`.
- Добавлен `static/css/layout.css` для общей ширины страниц и адаптивности.
- Старые одноразовые CSS-патчи страницы входа и общей таблицы удалены из `task_review.css`.
- Широкие правила таблицы задач теперь применяются только к `[data-task-table]`, а не ко всем таблицам проекта.
- Названия задач на временной шкале переносятся максимум на две строки; слишком длинные подписи автоматически выравниваются влево.

## Зачем

Основная цель — убрать накопившиеся локальные патчи, снизить дублирование и сделать интерфейс предсказуемым на широких экранах.
