# Рефакторинг интерфейса и прав доступа — 2026-10

## Что изменено

- Удалён промежуточный `manager_views.py`: проверки владельца задачи перенесены в основной `views.py`.
- Контекст страницы задачи собирается через единый `_task_detail_context`, чтобы права и формы не расходились между GET и ошибочными POST.
- Очередь проверки и manager-dashboard используют единый `_manager_owned_queryset`.
- Добавлен `static/css/layout.css` для общей ширины страниц и адаптивности.
- Старые одноразовые CSS-патчи страницы входа и общей таблицы удалены из `task_review.css`.
- Широкие правила таблицы задач теперь применяются только к `[data-task-table]`, а не ко всем таблицам проекта.
- Названия задач на временной шкале переносятся максимум на две строки; слишком длинные подписи автоматически выравниваются влево.

## Зачем

Основная цель — убрать накопившиеся локальные патчи, снизить дублирование и сделать интерфейс предсказуемым на широких экранах.

## Рефакторинг модулей и ресурсов — 2026-10-25

- Обработчики задач выделены из `views.py` в `task_views.py`.
- Действия над задачей (переходы статуса, передача, комментарии и изображения) выделены в `task_action_views.py`.
- Дашборд, календарь и загрузка выделены в `team_views.py`; шаблоны, уведомления, отсутствия и идеи — в `department_views.py`.
- Общие выборки, правила доступа, контекст карточки, фильтры и безопасный redirect собраны в `task_view_helpers.py`.
- Аналитика, выгрузки и мониторинг backup выделены в `reporting_views.py`.
- `signals.py` оставлен для регистрации сигналов; запись истории и уведомления находятся в `task_event_handlers.py`.
- URL names и пути сохранены; изменены только модули обработчиков.
- Локальные CSS/JS используют версию приложения из `VERSION` для cache busting.
- Основные рабочие страницы вынесены в верхнюю навигацию; очередь проверки руководителя получила отдельный вход и счётчик. Чат, документы, идеи и административные разделы сгруппированы в меню «Ещё».
- Меню «Ещё» разделено на группы, подсвечивает текущий раздел и прокручивается на небольших экранах; мобильная навигация переносится на следующую строку, чтобы выпадающее меню не обрезалось.
- Django system check и проверка миграций прошли на Python 3.14; production image использует Python 3.13. Полный pytest сохранил 7 известных падений, перечисленных в release notes v0.9.18.
